# **App Name**: Picture Poet

## Core Features:

- Image Upload: Allow users to upload or drag and drop a photo.
- Poem Generation: Use a generative AI tool to analyze the image and generate a poem based on its content, style, and mood.
- Poem Display: Display the generated poem alongside the uploaded image.
- Poem Saving/Copying: Allow users to save or copy the generated poem.

## Style Guidelines:

- Primary color: Earthy tones to evoke a natural and artistic feel.
- Secondary color: Muted blues and greens to complement the earthy tones.
- Accent: A soft lavender (#E6E6FA) to add a touch of creativity and sophistication.
- Elegant and readable typography to enhance the poetic experience.
- Clean and simple layout to focus on the image and poem.
- Subtle animations when poem is generated or when interacting with the image.

## Original User Request:
An app that generates poems from photos
